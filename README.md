# 🔧 Technical‑Service Field App

> A mobile app for field technicians — a guided job flow, shift tracking and on‑site job management.

A field‑service app built for on‑site technical teams (installation, repair and maintenance). Technicians start their shift, create a new job through a clear step‑by‑step wizard, and keep all their work organized in one place.

> ℹ️ This is a **showcase repository** — documentation and screenshots only. The source code is private.

---

## ✨ Features

- 🧭 **Guided 9‑step job flow** — choose the operation type (installation / repair / maintenance) and walk through each step without missing anything.
- ⏱️ **Shift tracking** — "start work" when the day begins; activity is tied to the shift.
- 📋 **My jobs** — active, pending, completed and past jobs in one list, with full history.
- 📦 **Stock entry** and **bulk‑job** support for busy days.
- 🏢 Built for multi‑technician service businesses (e.g. HVAC sales & service).
